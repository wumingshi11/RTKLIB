## 本模块在整条学习链中的作用

模块 B/C 已经把“卫星在哪、伪距怎么改正、怎么单点定位”讲完了，但那只够**米级**定位。  
要走到 **RTK 厘米级**，必须用载波相位，而载波相位有三大难题，正好是本模块要解决的：

| 难题 | 本模块对应内容 |
|---|---|
| 载波相位有未知整周模糊度，不能直接当距离 | D1：认识 λN |
| 观测里混着几何、钟差、电离层、对流层，需要“提纯” | D2：GF / MW 等线性组合 |
| 信号可能失锁/周跳，导致模糊度不连续 | D3：周跳检测（GF/MW/LLI） |

**一句话作用**：

> 模块 D 是“从米级伪距走向厘米级载波”的桥梁——它让我们学会：
> 1. 把载波相位这个“精密但带模糊度”的观测用起来；
> 2. 用线性组合把不想要的项消掉、把想要的项（模糊度/电离层）露出来；
> 3. 保证模糊度在时间上连续（检测周跳），为 E/F 模块的 RTK 浮点解和模糊度固定铺路。

## D1 载波相位与整周模糊度（真实数字）

第 1 个历元 G03：

| 量 | 值 |
|---|---|
| L1 | 55,923,622.160 cycle |
| λ1·L1 | 10,641,911.457 m |
| L2 | 43,647,388.242 cycle |
| λ2·L2 | 10,659,137.998 m |
| C1（伪距） | 24,767,686.375 m |
| 参考几何距离 ρ | ≈ 24,873,907.226 m |
| λ1·L1 − ρ | -14,231,995.769 m（≈ λ1·N1） |
| λ2·L2 − ρ | -14,214,769.228 m（≈ λ2·N2） |

**结论**：

- 载波相位观测值 `L` 是 **cycle**，乘上波长后虽然和几何距离同数量级（千万米），但**差一个未知整周模糊度 λN**（本例约 -1420 万 m）；
- 所以载波相位不能直接当几何距离用；
- 但载波相位噪声是**毫米级**，比伪距（分米~米级）精密得多，是后续 RTK 高精度的基础。

## D2 线性组合：GF 与 MW（真实序列）

### 线性组合的参数选取原理

双频线性组合的一般形式（以米为单位的两个载波/码观测）：

$$
Z = a\,X_1 + b\,X_2
$$

其中 $X_1, X_2$ 是 L1/L2 的观测（米），$(a,b)$ 就是**两个组合参数**。选参数的原则是：**想消掉哪一项，就让那一项的系数和为零**。

以载波相位（米）为例，主要项的系数是：

| 项 | L1 中的系数 | L2 中的系数 |
|---|---|---|
| 几何/钟差 | 1 | 1 |
| 电离层（一阶，∝1/f²） | 1/f1² | 1/f2² |
| 模糊度 | λ1 | λ2 |

所以：

- **要消几何/钟差**：令 $a + b = 0$ → GF；
- **要消电离层**：令 $a/f_1^2 + b/f_2^2 = 0$ → IF；
- **要保持几何**：令 $a + b = 1$（归一化）。

### 常用组合与取值（GPS L1/L2）

| 组合 | 参数 (a, b)（对米观测） | 消掉 | 保留 | 波长/特点 |
|---|---|---|---|---|
| **GF 几何无关** | (1, -1) | 几何、钟差、对流层 | 电离层 + 模糊度 | 无固定波长，噪声放大 |
| **IF 无电离层** | (2.5457, -1.5457) | 一阶电离层 | 几何 + 模糊度 | 模糊度通常非整数 |
| **WL 宽巷**（周） | (1, -1)（对周） | 部分电离层 | 几何 + 宽巷模糊度 | λw = 0.8619 m |
| **NL 窄巷**（周） | (f1, f2)/(f1+f2) | 部分电离层 | 几何 + 窄巷模糊度 | λn = 0.10695 m |
| **MW** | 宽巷相位 − 窄巷码 | 几何、钟差、电离层 | 宽巷模糊度 + 码噪声 | 常用于周跳/模糊度初始化 |

具体数值（GPS L1/L2）：

$$
\alpha_{IF} = \frac{f_1^2}{f_1^2-f_2^2} = 2.5457,\quad
\beta_{IF} = -\frac{f_2^2}{f_1^2-f_2^2} = -1.5457
$$

$$
\lambda_w = \frac{c}{f_1-f_2} = 0.8619\ \text{m},\quad
\lambda_n = \frac{c}{f_1+f_2} = 0.1070\ \text{m}
$$

> 本模块用到的 **GF 就是 (1, -1)**，**MW 就是“宽巷相位 − 窄巷码”**，是上面通用框架的两个特例。

### GF（几何无关，Geometry-Free）

$$
GF = \lambda_1 L_1 - \lambda_2 L_2
$$

它**消掉几何距离、钟差、对流层**，剩下电离层 + 模糊度。

### MW（Melbourne–Wübbena）

$$
MW = \frac{f_1(\lambda_1 L_1) - f_2(\lambda_2 L_2)}{f_1 - f_2} - \frac{f_1 P_1 + f_2 P_2}{f_1 + f_2}
$$

除以宽巷波长 λw 后单位是**宽巷周数**。它消掉几何、钟差、电离层（一阶），主要剩**宽巷模糊度 + 码噪声**。

- 上表 MW 几乎常数（约 -16,459,300 cyc），变化约 **0.7 cyc**，来自码噪声；
- 所以 MW 的历元间跳变也是周跳检测工具。

> ⚠️ 注意：MW 公式里的载波要用**米**（λ·L），不能直接把 cycle 代进去，否则几何不会消干净（这是我们推导时踩过的坑）。

## D3 周跳：人为给 L1 加周跳，看 GF/MW 响应

以第 3 个历元为基准：

| 情形 | GF (m) | ΔGF | MW (cyc) | ΔMW |
|---|---|---|---|---|
| 原始 | -17226.481 | - | -16459300.204 | - |
| L1 +1 周 | -17226.291 | +0.190 | -16459299.204 | +1.000 |
| L1 +5 周 | -17225.530 | +0.951 | -16459295.204 | +5.000 |

**检测周跳的原理**：

> GF 在**正常锁定期间基本稳定**，只随电离层缓慢变化 + 噪声小幅波动（本例 30 s 一档，GF 每历元变化只有 cm 级）；  
> 一旦发生**失锁/周跳**，L1 或 L2 会突然跳变整数周，GF 就会产生一个**离散跳变**（+1 周 L1 ≈ +0.190 m），远大于正常波动。  
> 所以用“GF 历元间差分超过阈值”就能检测周跳。MW 类似，而且更平（还消了一阶电离层），也常用于周跳检测。

**结论**：

- GF 对 L1 单频周跳敏感：+1 周 ≈ +0.190 m（正好是 λ1）；
- MW 对周跳也敏感：+1 周 L1 → MW 约 +1 周；
- 实际检测常用：
  1. **GF 历元间差分**（阈值如几 cm）；
  2. **MW 与上一历元比较**（阈值如 0.5~1 周）；
  3. **LLI 标志**（接收机硬件直接给失锁/周跳指示）。
