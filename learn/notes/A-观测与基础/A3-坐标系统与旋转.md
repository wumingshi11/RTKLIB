## 1. 三个坐标系

| 坐标系 | 含义 | 单位 | 用途 |
|---|---|---|---|
| **ECEF** | 地心地固（x/y/z，原点地心，随地球自转） | m | 卫星位置/接收机位置 |
| **LLH** | 大地坐标（lat/lon/height，WGS84 椭球） | rad/rad/m | 用户可读坐标 |
| **ENU** | 站心（东/北/天），原点在接收机处 | m | 视线、高度角、误差分析 |

### 1.1 ECEF 三轴定义（WGS84）

| 元素 | 指向 |
|---|---|
| 原点 O | 地球质心（地心） |
| **Z 轴** | 指向**协议地球极 CTP**（≈ 平均北极，即地球自转轴方向，WGS84 用 BIH 1984.0 CTP） |
| **X 轴** | 赤道面内，指向**本初子午线（0° 经线）与赤道的交点** |
| **Y 轴** | 赤道面内，**东经 90°** 方向，与 X、Z 成**右手系** |

```text
        Z（北极 / 协议极 CTP）
        ↑
        |        · P(x,y,z)
        |       /|
        |      / | φ 纬度
        |     /  |
        |    /   |
        |   /    |
        |  /     |
        | /      |
        |/λ 经度 |
        └────────┴──────→ Y（90°E，赤道面）
       / 
      X（0° 经线，赤道面）
```

三个关键点：

1. **X 轴 = 0° 经线**，所以经度 λ 从 X 轴绕 Z 轴起算——直接体现在代码里：
   - `pos2ecef`：`r[1]` 带 $\sin\lambda$、`r[0]` 带 $\cos\lambda$ → λ 从 X 轴起算；
   - `ecef2pos`：`pos[1]=atan2(r[1],r[0])` → 经度 = $\mathrm{atan2}(y,x)$，绕 Z 从 X 起算。
2. **Z 轴是"协议"极，不是瞬时自转轴**：WGS84 用 BIH 1984.0 的 CTP（平均方向），与真实瞬时自转轴差约 0.005″，这正是极移的物理来源（`eci2ecef` 里的 `erpv[0]/[1]` 就是极移修正）。
3. **X 轴的"本初子午线"**：精确说是指向 **IERS 参考子午线 (IRM)** 与赤道的交点，与格林尼治天文台老零子午线差约 5.3″（赤道处约 100 m）。

### 1.2 三个坐标系的角色与用途

**关键区分**：
- **ECEF 和 LLH 是"同一个点的两种写法"**（一个直角、一个经纬高），`ecef2pos`/`pos2ecef` 互转；
- **ENU 不是"点的位置"，是"向量坐标系"**——只描述"某个方向/位移在东、北、天各有多少"，不回答"点在哪"；
- **LLH 提供定义 ENU 框架的纬经**（天向 = 该点法线方向），ENU 用它建系，但三者不是递进转换链。

```text
ECEF (x,y,z) ──ecef2pos──► LLH (lat,lon,h)   ← 同一点的两种表示
   │                              │
   │ ecef2enu (xyz2enu)           │ 提供纬经，定"天向"
   ▼                              ▼
ENU (e,n,u)                   建立局部系
```

**何时用 ECEF —— 凡是"全局计算"都在 ECEF**（与卫星位置、地心模型同框架）：
- 卫星位置/速度：`eph2pos`/`satposs` 输出 ECEF；
- 几何距离、视线向量：`geodist(rs,rr,e)` 全 ECEF；
- 定位求解与滤波：`rescode` 的状态 $x=[r_x,r_y,r_z,c\delta t]$、雅可比、协方差 $P$ 都是 ECEF；
- 单差/双差残差、Kalman 更新的位置状态。

**何时用 ENU —— 凡是"要用人能理解的方向"才转 ENU**：
- 高度角/方位角：`satazel` 内部 `ecef2enu` → $el=\arcsin(e_U)$、$az=\mathrm{atan2}(e_E,e_N)$——选星、高度角定权、SNR 掩码都依赖它；
- 误差分解：`covenu` 把 ECEF 协方差转到 ENU，得到 E/N/U 各自的 1σ 精度（报告"水平/垂直精度"）；
- 基线输出：差分解用 ENU 基线（`SOLF_ENU`，`sol_t.rr` type=1 是 {e,n,u,ve,vn,vu}）；
- 接收机天线 PCV（按 ENU 定义）、多径与高度角关系。

**RTKLIB 实际路径**：

```text
geodist(rs,rr,e)          ← 全 ECEF：ρ 和视线 e
satazel(pos, e, azel)     ← pos=LLH，e=ECEF → 内部 ecef2enu → az/el
xyz2enu(pos,E)            ← 用 LLH 的纬经构造旋转矩阵 E
ecef2enu(pos,r,e)         ← e = E·r（ECEF → ENU）
covenu(pos,P,Q)           ← 协方差 ECEF → ENU（精度报告）
pntpos/rtkpos 内部         ← 位置状态、残差、雅可比全部 ECEF
```

> **一句话**：ECEF 是"算"的坐标系（全局、唯一、与卫星同框），ENU 是"看"的坐标系（东/北/天，讲方向、高度角和误差），LLH 是"给人看"的点和定义 ENU 框架的桥。

### 1.3 直觉理解：ENU = "以一点为原点"看 ECEF 向量

**ENU 就是把 ECEF 下两个点的差向量，以其中一个点为原点，投影到由该点经纬度定义的局部坐标系（东/北/天）下。**

- "以一个点为原点" = ENU 原点放在接收机位置（由 LLH 的 lat/lon/h 定）；
- "该向量的坐标" = 两个 ECEF 点之差 $r=p_{sat}-p_{rcv}$ 投影到 ENU 三轴的 $(e,n,u)$；
- "方向由经纬度决定" = 三个轴方向只由 lat/lon 决定（h 只挪原点、不改方向）。三轴在 ECEF 中分别是：

$$E\text{ 轴（东）}=(-\sin\lambda,\ \cos\lambda,\ 0)$$
$$N\text{ 轴（北）}=(-\sin\varphi\cos\lambda,\ -\sin\varphi\sin\lambda,\ \cos\varphi)$$
$$U\text{ 轴（天）}=(\cos\varphi\cos\lambda,\ \cos\varphi\sin\lambda,\ \sin\varphi)$$

这三个向量恰好就是旋转矩阵 $E$ 的**三行**——所以 $\mathbf e=E\,\mathbf r$ 本质是"**把 ECEF 相对向量分别向三个局部轴做投影**"，一次换基底，不含任何平移。

## 2. ECEF→ENU 旋转矩阵（手推）

### 2.1 手推三步法：基本旋转矩阵 → 两次旋转 → 相乘

**第 1 步：先知道"一个角度变化如何用矩阵表示"**——绕三个坐标轴的**基本旋转矩阵**（右旋，列向量左乘）：

$$R_x(\alpha)=\begin{pmatrix}1&0&0\\0&\cos\alpha&-\sin\alpha\\0&\sin\alpha&\cos\alpha\end{pmatrix},\quad
R_y(\alpha)=\begin{pmatrix}\cos\alpha&0&\sin\alpha\\0&1&0\\-\sin\alpha&0&\cos\alpha\end{pmatrix},\quad
R_z(\alpha)=\begin{pmatrix}\cos\alpha&-\sin\alpha&0\\\sin\alpha&\cos\alpha&0\\0&0&1\end{pmatrix}$$

RTKLIB 里对应 `Rx/Ry/Rz` 三个宏（`rtkcmn.c`，列主序存储），代码与公式一一对应。

**第 2 步：把 ECEF→ENU 拆成两次旋转**（先绕 Z，再绕新 X）：

1. 绕 Z 轴旋转 $-(\lambda+\tfrac{\pi}{2})$——把"东方向"转到 X 轴（赤道面内）；
2. 绕 X 轴旋转 $\varphi-\tfrac{\pi}{2}$——把"天方向"转到 Z 轴（子午面内）。

$$E=R_x(\varphi-\tfrac{\pi}{2})\;R_z(-(\lambda+\tfrac{\pi}{2}))$$

**第 3 步：两个矩阵相乘**（注意顺序：先作用的在右边，$E\,r$ 先被 $R_z$ 作用）：

$$R_z(-(\lambda+\tfrac{\pi}{2}))=\begin{pmatrix}-\sin\lambda&\cos\lambda&0\\-\cos\lambda&-\sin\lambda&0\\0&0&1\end{pmatrix},\qquad
R_x(\varphi-\tfrac{\pi}{2})=\begin{pmatrix}1&0&0\\0&\sin\varphi&\cos\varphi\\0&-\cos\varphi&\sin\varphi\end{pmatrix}$$

$$E=R_x(\varphi-\tfrac{\pi}{2})\,R_z(-(\lambda+\tfrac{\pi}{2}))=\begin{pmatrix}
-\sin\lambda & \cos\lambda & 0\\
-\sin\varphi\cos\lambda & -\sin\varphi\sin\lambda & \cos\varphi\\
\cos\varphi\cos\lambda & \cos\varphi\sin\lambda & \sin\varphi
\end{pmatrix}$$

### 2.2 验证

- 天向（第 3 行）= 地心方向单位向量 $(\cos\varphi\cos\lambda,\ \cos\varphi\sin\lambda,\ \sin\varphi)$；
- 东向（第 1 行）垂直于经线切线；北向（第 2 行）由"东向 × 天向"的手性关系定；
- 三行两两正交、模为 1（正交矩阵），且 $\det E=+1$（纯旋转、无镜像）。

## 3. 对应代码（`src/rtkcmn.c`）

```c
extern void xyz2enu(const double *pos, double *E)
{
    double sinp=sin(pos[0]),cosp=cos(pos[0]),sinl=sin(pos[1]),cosl=cos(pos[1]);
    E[0]=-sinl;      E[3]=cosl;       E[6]=0.0;
    E[1]=-sinp*cosl; E[4]=-sinp*sinl; E[7]=cosp;
    E[2]=cosp*cosl;  E[5]=cosp*sinl;  E[8]=sinp;
}
```

- `xyz2enu(pos,E)`：构造旋转矩阵 $E$（**列主序**存储，见注释）。
- `ecef2enu(pos,r,e)`：`matmul("NN",3,1,3,1.0,E,r,0.0,e)` —— $\mathbf e = E\,\mathbf r$。
- `enu2ecef(pos,e,r)`：`matmul("TN",3,1,3,1.0,E,e,0.0,r)` —— 转置 $E^T$ 反向变换。
- `satazel(pos,e,azel)`：把 ECEF 视线转到 ENU，$az=\mathrm{atan2}(e_E,e_N)$、$el=\mathrm{asin}(e_U)$。

其他：`pos2ecef`/`ecef2pos` 是 LLH↔ECEF（含椭球迭代）；`covenu`/`covecef` 是协方差变换（第 3 周用）。

## 4. 验证

- 手推旋转矩阵与 `xyz2enu()` 数组逐元素对照（注意列主序）。
- 任给一个 ECEF 视线向量，转 ENU 后手算高度角，与 `satazel()` 一致。
