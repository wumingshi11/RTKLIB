## 1. 时间系统概念

| 时间系统 | 说明 | 与 GPST 关系 |
|---|---|---|
| **GPST**（GPS 时间） | 起点 1980-01-06 00:00 UTC；连续、无闰秒；= TAI − 19 s | 基准 |
| **UTC** | 民用时，含闰秒（不连续） | UTC = GPST − 闰秒数（当前 18 s） |
| **GST**（Galileo） | 起点 1999-08-22；连续、无闰秒 | 与 GPST 差为**常数**（GGTO），精确值以 Galileo 广播参数为准 |
| **BDT**（北斗） | 起点 2006-01-01 00:00 UTC；连续、无闰秒 | GPST − 14 s |
| **GLONASS** | 用莫斯科 UTC（UTC(SU)） | 与 UTC 相差整秒级 |

- **周数 + 周内秒（TOW）**：GPS 用"周号（week）＋ 周内秒（0~604799 s）"表示绝对时刻，避免直接用大秒数。
- **闰秒表**：`src/rtkcmn.c` 里的 `leaps[][]` 数组（当前到 2017 年 −18 s）。

> 📌 **为什么有多个系统时间、而 GPST 不是"标准时间"？**
>
> - 真正的标准是原子时 **TAI** 和由它导出的 **UTC**；GPST 只是 GPS 的内部时标。
> - 各系统由不同国家运营、独立定义系统时间，但**都锚定连续原子时 TAI**，只差一个**常数偏置**（表盘零位不同，走速相同）。
> - 例：GPST = TAI − 19 s，BDT = TAI − 33 s → GPST − BDT = 14 s（来自起点年份的闰秒累计差，**不是时间差在累积**）。
>
> 📌 **为什么系统内部不用 UTC？**
>
> - UTC 会**插闰秒**（时标跳变、不连续），对需要连续时标的导航系统是灾难；
> - 所以 GNSS 内部用**无闰秒的连续系统时间**，对外再用 UTC 参数 + 闰秒表换算。
>
> 📌 **系统间的时间差会漂移吗？有纠正吗？**
>
> - "十几秒"的常数偏置**不漂**；会微漂的只是系统间**残差**（各系统地面原子钟组间相对钟漂，约 $10^{-13}\sim10^{-14}$ → 微秒级/天）。
> - 纠正机制三层：① 各自地面段把系统时间对准 TAI/UTC；② 广播改正参数（如 Galileo 广播 GGTO）；③ 接收端把**系统间偏差 ISB** 当未知参数估计（见 C 模块）。
> - 残差远小于常数偏置，实际只有微秒级。

### 背景：TAI / UTC / 系统时间是怎么来的

- **TAI（国际原子时）**：1958 年起由全球原子钟平均得到，绝对均匀、**无闰秒**。
- **UTC（协调世界时）**：1972 年起 = TAI − 累积闰秒，靠**闰秒**跟着地球自转走。
- **GPST 的设计**：1970 年代设计 GPS 时，选 **1980-01-06 00:00 UTC** 为纪元，并固定为 **TAI − 19 s**——既继承了 UTC 的历史起点，又从此**不受闰秒影响**（连续时标）。
- **后来的 BDT / GST** 照同一思路：锚定 TAI、各取一个**常数偏置** → 系统间只差常数（这就是"为什么只差十几秒"的根源）。
- **闰秒由 IERS 决定**，只在 6/30 或 12/31 的 UTC 插入；实际插入**不定期**（间隔 6 个月~7 年），由地球自转与原子时之差是否累积到 ~0.9 s 决定。**2017 年后至今未再插入**（近年地球自转未明显变慢，甚至略加快）。

> **设计哲学一句话**：导航要**连续时标**，就绕开闰秒；对外再靠**闰秒表**把用户需要的 UTC 算回来。

## 2. gtime_t 与时间函数（`src/rtkcmn.c`）

```c
typedef struct { /* time struct */
  time_t time;   /* 秒（标准 time_t，从 1970-01-01 起） */
  double sec;    /* 1 秒以内的小数部分 */
} gtime_t;
```

| 函数 | 作用 | 关键点 |
|---|---|---|
| `gpst2time(week, tow)` | 周+周内秒 → `gtime_t` | `gpst0={1980,1,6,0,0,0}` 起算 |
| `time2gpst(t, &week)` | `gtime_t` → 周+周内秒 | 返回 TOW |
| `timediff(t1,t2)` | t1−t2（秒） | `difftime + sec 差` |
| `timeadd(t, sec)` | 时间加秒 | 进位/借位处理 |
| `epoch2time`/`time2epoch` | 年月日↔`gtime_t` | 闰年按 1901~2099 简化规则 |
| `gpst2utc`/`utc2gpst` | GPST↔UTC | 查闰秒表 |
| `gst2time`/`bdt2time` | 其他系统时间 | `gst0`/`bdt0` 参考点 |
