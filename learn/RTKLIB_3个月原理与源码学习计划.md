# RTKLIB 三个月原理与源码学习计划

> 适用版本：本仓库 RTKLIB 2.4.3 b34
>
> 周期：12 周，每周 10 小时，共约 120 小时
>
> 主线：伪距 → 载波相位 → 差分残差 → RTK 浮点解 → 周跳与模糊度管理 → LAMBDA 固定解
>
> 最终目标：能独立解释、定位并修改 RTKLIB 的核心相对定位流程，能导出浮点阶段的残差、雅可比和协方差。本文不把 LiDAR 融合原型列为结业要求。

## 1. 三个月后的验收标准

完成本计划后，应能在不照抄资料的情况下完成以下任务：

1. 从信号传播过程写出伪距、载波相位和多普勒观测方程，逐项说明单位、符号、误差来源及可观性。
2. 推导站间单差、星间单差和双差，说明哪些误差被消除、哪些仅被削弱、哪些仍需估计。
3. 从 `rnx2rtkp` 入口追踪一个历元，讲清数据如何从 RINEX 进入 `obsd_t`，最终形成 RTK 浮点解和固定解。
4. 解释 `rtkpos()`、`relpos()`、`zdres()`、`ddres()`、`ddcov()`、`filter()`、`resamb_LAMBDA()` 和 `lambda()` 之间的数据流。
5. 对 `rtk_t.x`、`rtk_t.P` 中的位置、对流层、电离层、硬件偏差和单差模糊度状态给出索引、单位、初始化方法和时间更新模型。
6. 对 `ddres()` 产生的每一行残差，指出参考星、目标星、频点、观测类型、雅可比非零块和协方差来源。
7. 解释 LLI 和几何无关组合如何触发周跳，以及周跳后模糊度状态如何重置；同时指出本版本相对定位中的多普勒检测路径为何实际未启用。
8. 手算一个 2～3 维整数最小二乘例子，并将结果与 `lambda()` 输出相互验证。
9. 导出一个历元浮点阶段的 `v`、`H`、`R`、`x`、`P` 和 `vflg`，验证维度、单位、对称性与正定性。
10. 独立修改一种观测噪声或质量控制策略，设计对照实验，并用残差、浮点误差和固定率解释结果。

如果其中第 6、8、9、10 项不能完成，就不算“深入掌握”，应回到对应周复习。

## 2. 学习方法：每周必须形成闭环

每周 10 小时固定分配如下，可拆为 5 个 2 小时学习块：

| 模块 | 时间 | 必须产出 |
|---|---:|---|
| 理论与手推 | 2 h | 公式推导纸稿或 Markdown 笔记，不能只摘抄结论 |
| 源码精读 | 3 h | 调用链、关键变量表、至少 5 条行内批注 |
| 运行与实验 | 3 h | 命令、配置、日志/曲线、现象解释 |
| 复盘与口述 | 1 h | 不看资料讲 10～15 分钟，记录卡住的位置 |
| 问题清单 | 1 h | 本周答案、未解问题、下周需验证的假设 |

### 每个主题的四遍阅读法

1. **第一遍看接口**：只看函数注释、输入输出、数据单位，不进入实现。
2. **第二遍看公式**：把代码中的每一项映射到手推公式，尤其检查正负号和米/周/秒单位。
3. **第三遍看数据**：用一个历元打断点或 trace，记录真实数组维度和数值范围。
4. **第四遍做改动**：只改一个因素，运行对照实验，观察残差和解状态如何改变。

每次读源码前先写下“这个函数理论上应该做什么”，读完后对照差异。这样能避免被 C 语言细节牵着走。

### 3.3 两个必须牢记的实现约定

- RTKLIB 的矩阵采用 **column-major（列主序）**。
- `filter()` 注释中的 `H` 是设计矩阵的转置，内存维度为 `n × m`：`n` 个状态、`m` 个观测。若习惯写成残差雅可比 `J (m × n)`，则代码里的 `H = J^T`。

## 第 1 周：建立观测量、时间、坐标和数据结构的统一认识

### 本周核心问题

RINEX 中的一行观测进入 RTKLIB 后到底以什么单位保存？时间、卫星编号、频点和码类型如何关联？

### 理论与手推（2 h）

1. 写出三个基本观测方程：

   \[
   P_r^s=\rho_r^s+c(\delta t_r-\delta t^s)+T_r^s+I_r^s+d_{P,r}-d_P^s+\epsilon_P
   \]

   \[
   \lambda\Phi_r^s=\rho_r^s+c(\delta t_r-\delta t^s)+T_r^s-I_r^s+\lambda N_r^s+d_{\Phi,r}-d_\Phi^s+\epsilon_\Phi
   \]

   \[
   D_r^s\lambda\approx-\dot\rho_r^s-c(\dot{\delta t}_r-\dot{\delta t}^s)+\epsilon_D
   \]

2. 建立单位表：`P` 为 m，`L` 为 cycle，`D` 为 Hz，`SNR` 在本版本中按 `0.001 dBHz` 保存，卫星位置为 ECEF m，钟差通常为 s。
3. 复习 GPST/UTC、周数/周内秒、ECEF/LLH/ENU；手推 ECEF 到 ENU 的旋转矩阵。

### 源码精读（3 h）

按顺序阅读：

1. `src/rtklib.h`：`gtime_t`、`obsd_t`、`obs_t`、`eph_t`、`nav_t`、`sol_t`。
2. `src/rtkcmn.c`：`gpst2time()`、`time2gpst()`、`timediff()`、`pos2ecef()`、`ecef2pos()`、`ecef2enu()`、`geodist()`、`satazel()`。
3. `src/rinex.c`：`readrnx()` 到 `decode_obsdata()` 的调用关系；暂不追每种 RINEX 版本分支。

必须画出：

```text
RINEX observation text
  -> readrnx/readrnxt
  -> readrnxobs/readrnxobsb
  -> decode_obsepoch + decode_obsdata
  -> obsd_t {time,sat,rcv,P,L,D,SNR,LLI,code}
  -> obs_t.data
```

### 实验（3 h）

1. 构建 `rnx2rtkp`，记录编译器和依赖问题；不要在本周花时间优化构建系统。
2. 用调试器停在 `decode_obsdata()`，只观察第一个有效历元的 2～3 颗 GPS 卫星。
3. 建表记录 `sat/code/P/L/D/SNR/LLI`，用 `satno2id()` 和 `code2obs()` 转成人类可读形式。
4. 用 `sat2freq()` 算波长，验证 `L × λ` 的量级接近几何距离，但包含未知整周常数。

### 本周产出与验收（2 h）

- `notes/week01_observation_types.md`：数据结构和单位表。
- `diagrams/week01_rinex_to_obs.md`：数据流图。
- 口述验收：为什么 `L` 不能直接当米使用？`code[]` 为什么不能只用数组下标替代？
- 常见误区：把接收时刻当发射时刻；混淆载波相位 cycle 与距离 m；忽略不同星座/频点的频率差异。

## 第 2 周：广播星历、卫星位置钟差和几何距离

### 本周核心问题

伪距残差形成之前，RTKLIB 如何从星历得到“信号发射时刻”的卫星位置与钟差？

### 理论与手推（2 h）

1. 从开普勒参数推导 GPS 广播星历位置计算流程：平均角速度、平近点角、偏近点角、真近点角、升交距角、轨道面改正、ECEF 旋转。
2. 推导卫星钟差多项式和相对论改正的来源与单位。
3. 写清发射时刻迭代、地球自转 Sagnac 改正为什么存在。
4. 给定一颗卫星的 `rs[0:3]` 和接收机 ECEF，手算视线单位向量 `e` 与几何距离 `ρ`。

### 源码精读（3 h）

1. `src/rinex.c`：`decode_eph()`、`add_eph()`。
2. `src/ephemeris.c`：`seleph()`、`eph2clk()`、`eph2pos()`、`ephpos()`、`satpos()`、`satposs()`。
3. `src/rtkcmn.c`：`geodist()`；定位其中的地球自转改正。
4. 区分 `rs` 的 6 个元素、`dts` 的 2 个元素、`var` 和 `svh`。

### 实验（3 h）

1. 选第 1 周的一颗 GPS 卫星，记录 `satposs()` 输出的发射时刻估计、位置、速度、钟差、钟漂和方差。
2. 独立写一个只针对 GPS 的最小计算表或小程序，用同一广播星历计算卫星位置；目标不是重写完整库，而是逐项核对中间量。
3. 分别关闭/保留卫星钟差和 Sagnac 项，记录伪距预测变化量。

### 本周产出与验收（2 h）

- `notes/week02_ephemeris.md`：公式与 `eph2pos()` 代码逐项映射。
- 一张“接收时刻 → 发射时刻 → 卫星状态”的调用图。
- 数值验收：独立计算与 RTKLIB 的卫星位置应达到可解释的一致；若不一致，优先检查时间系统、角度单位和矩阵方向。

## 第 3 周：伪距模型、加权最小二乘与 SPP 残差

### 本周核心问题

`pntpos()` 如何把多个伪距变成接收机位置？残差、雅可比、权重和钟差状态分别在哪里？

### 理论与手推（2 h）

1. 以状态 `x=[r_x,r_y,r_z,cδt_r,...]^T` 线性化伪距方程，推导位置块雅可比 `-e^T` 和钟差列。
2. 推导加权最小二乘：

   \[
   \delta x=(H^TWH)^{-1}H^TWv
   \]

3. 理解多星座接收机钟差/系统间偏差为何增加状态。
4. 对流层、电离层、TGD、卫星钟差、天线和测量噪声逐项建立“改正值/残余误差”表。

### 源码精读（3 h）

1. `src/pntpos.c`：`prange()`、`ionocorr()`、`tropcorr()`、`rescode()`、`estpos()`、`valsol()`、`raim_fde()`、`pntpos()`。
2. `src/rtkcmn.c`：`lsq()` 和列主序矩阵调用。
3. 跟踪 `rescode()` 中 `v`、`H`、`var`、`vsat`、`resp` 的定义和写入位置。
4. 明确代码里的 `H` 与教科书 `H` 是否转置，给出确切维度。

### 实验（3 h）

1. 仅运行单点定位，开启 trace，截取一个历元。
2. 导出或人工抄录该历元每颗卫星的观测伪距、预测伪距、改正项、残差、方差和视线向量。
3. 用这些数据独立做一次 WLS 更新，与 `estpos()` 第一次迭代对比。
4. 对比高度角截止角 5°、15°、30° 时的卫星数、GDOP、残差和位置变化。

### 阶段 A 验收（2 h）

- 画出 `pntpos → satposs → estpos → rescode → lsq` 调用链。
- 随机挑一个 `rescode()` 残差，能够从原始 `P` 重建到 0.1 m 量级的一致；未包含的模型项必须明确列出。
- 不看源码讲清 `v = measurement - prediction` 的符号，以及代码中位置雅可比为何是相应符号。

## 第 4 周：载波相位、线性组合和周跳可观测量

### 本周核心问题

载波相位为何能达到毫米级噪声却仍有整数模糊度？不同组合在消除误差时付出了什么代价？

### 理论与手推（2 h）

1. 从接收机和卫星振荡器相位写出载波相位观测方程，解释初始整周模糊度和连续跟踪。
2. 推导几何无关组合、无电离层组合和 Melbourne–Wübbena 组合。
3. 对每种组合列出：保留/消除的几何项、钟差、电离层、模糊度、噪声放大系数和适用场景。
4. 解释半周有效性、LLI、相位缠绕、相位中心变化和整周跳变。

### 源码精读（3 h）

1. `src/rtkpos.c`：`sdobs()`、`gfobs()`、`detslp_ll()`、`detslp_gf()`、`detslp_dop()`；注意 `detslp_dop()` 的主体被 `#if 0` 禁用，阅读它是为了理解设计意图，不能把它当成当前有效检测器。
2. `src/rtkpos.c::zdres_sat()`：核对无电离层组合的系数、单位和噪声代价。
3. 补充阅读 `src/ppp.c::gfmeas()`、`mwmeas()` 和 `corr_meas()`：借此核对 GF、MW 和无电离层组合公式；明确 `mwmeas()` 属于 PPP 路径，当前 `relpos()` 相对定位流程并未调用它。
4. `src/rtklib.h`：`ssat_t` 中 `slip/half/lock/outc/slipc/gf/mw/pt/ph` 的角色。
5. 区分观测文件中的 `obsd_t.LLI` 与定位状态中的 `ssat_t.slip`。

### 实验（3 h）

1. 从双频数据提取一颗卫星连续若干历元的 `L1/L2/P1/P2`。
2. 自己计算 GF 和 MW 序列，画出时间序列；估计无周跳区间的均值和标准差。
3. 人工给一个历元的 L1 加 `+1 cycle`、`+5 cycles`，观察离线计算的 GF/MW 以及相对定位代码中 GF 周跳标志的响应；不要把 MW 图的响应误认为 `relpos()` 使用了 MW 检测。
4. 记录相位缺测、重新捕获和低高度角对组合的影响。

### 本周产出与验收（2 h）

- 一张组合公式与 RTKLIB 函数对照表。
- 一张人工注入周跳前后的 GF/MW 图。
- 口述验收：为什么无电离层组合的模糊度通常不再是简单整数？为什么码噪声会污染 MW？

## 第 5 周：单差、双差残差及其完整协方差

### 本周核心问题

RTKLIB 在 `zdres()` 和 `ddres()` 中究竟差分了什么？为何双差残差之间相关，`R` 不能简单设成对角阵？

### 理论与手推（2 h）

1. 完整推导站间单差、星间单差、双差伪距和双差载波相位。
2. 明确短基线假设下卫星钟差、接收机钟差、轨道误差、电离层和对流层的消除程度。
3. 对同一参考星形成的双差向量，推导协方差：参考星误差造成所有双差之间的非零互协方差。
4. 推导双差相位的位置雅可比和两个模糊度状态列。

### 源码精读（3 h）

1. `src/rtkpos.c`：`selsat()`、`zdres_sat()`、`zdres()`、`validobs()`、`ddres()`、`ddcov()`、`varerr()`。
2. 分清 `zdres()` 输出的 `y` 已经减去了哪些项；不要把它误称为原始观测。
3. 逐行阅读 `ddres()`：星座分组、相位/码循环、最高高度角参考星、`v`、`H`、`Ri/Rj`、`vflg` 和 `nb`。
4. 解码 `vflg=(sat_i<<16)|(sat_j<<8)|(type<<4)|freq`。

### 实验（3 h）

1. 选一个共同可见卫星不少于 5 颗的历元，手工指定一颗参考星。
2. 从 `zdres()` 的 `y` 手工构造至少 3 条双差相位残差，和 `ddres()` 对比。
3. 根据单差方差手工构造对应 `3×3` 双差协方差，与 `ddcov()` 对比。
4. 改变参考星，验证双差向量与协方差虽改变，但携带的相对几何信息应等价；记录数值差异。

### 本周产出与验收（2 h）

- `notes/week05_ddres.md`：至少逐项解释一条相位残差和一条伪距残差。

- 硬验收：给出同组 3 条双差的完整 `R`，说明每一个非零非对角元素来自哪颗参考星。

## 第 6 周：RTK 状态布局、时间更新和浮点解测量更新

### 本周核心问题

双差模型如何进入 EKF？RTKLIB 估计的是双差模糊度还是单差模糊度？哪些状态为零时会被 `filter()` 排除？

### 理论与手推（2 h）

1. 写出 RTK 动态模型和测量更新；熟悉本仓库采用的协方差更新形式。
2. 讨论静态、运动学和 dynamics 模式的位置/速度/加速度状态。
3. 比较“滤波器保存单差模糊度、测量使用双差”与“直接保存双差模糊度”的优缺点。
4. 写出一个位置 + 两个单差模糊度的小型状态和一条双差相位测量的 `J`。

### 源码精读（3 h）

1. `src/rtkpos.c`：顶部 `NF/NP/NI/NT/NL/NB/NR/NX` 和 `II/IT/IL/IB` 宏。
2. `rtkinit()`、`initx()`、`udpos()`、`udion()`、`udtrop()`、`udrcvbias()`、`udbias()`、`udstate()`。
3. `relpos()` 中 `xp/Pp`、`ddres()`、`filter()`、post-fit `ddres()`、`valpos()` 的顺序。
4. `src/rtkcmn.c`：`filter_()` 和 `filter()`，尤其是 `x[i] != 0 && Pii > 0` 的活跃状态筛选。

### 实验（3 h）

## 第 8 周：整数最小二乘与 MLAMBDA 算法

### 本周核心问题

为什么逐个四舍五入浮点模糊度通常不是最优整数解？降相关与搜索如何降低计算量而不改变原问题？

### 理论与手推（2 h）

1. 写出整数最小二乘目标：

   \[
   \hat N=\arg\min_{N\in\mathbb Z^n}(N-\hat a)^TQ_{\hat a}^{-1}(N-\hat a)
   \]

2. 理解 `LDL^T` 分解、整数 Gauss 变换、置换、Z 变换、逐层枚举和候选距离。
3. 说明 decorrelation 改变搜索坐标但不改变整数解集合。
4. 理解 best/second-best 候选和 ratio test 的统计含义与局限，避免把阈值当绝对真理。

### 源码精读（3 h）

逐行阅读 `src/lambda.c`：

1. `LD()`：协方差分解。
2. `gauss()` 与 `perm()`：整数变换和置换。
3. `reduction()`：降相关循环。
4. `search()`：MLAMBDA 搜索、步进方向、距离界和候选排序。
5. `lambda()`：`a/Q → L/D/Z → z → E/s → F` 全流程。
6. 对照 `test/utest/t_lambda.c` 理解已有测试输入输出。

### 实验（3 h）

1. 构造一个相关性较强的 2 维浮点模糊度和协方差，画出误差椭圆与整数格点。
2. 手算或表格枚举最优两个整数候选，计算加权平方距离。
3. 调用 `lambda(n,2,a,Q,F,s)`，核对候选和 `s[0],s[1]`。
4. 逐步记录 reduction 前后的相关性和条件数；再用一个近奇异 `Q` 观察失败方式。

### 本周产出与验收（2 h）

- `notes/week08_lambda_walkthrough.md`：一个完整小例子。
- 能解释 `Z` 为什么必须保持整数可逆变换，以及 `solve("T",Z,E,...)` 如何回到原坐标。
- 能说明 ratio 大为何通常更可信，但为何不能据此证明固定一定正确。

## 第 9 周：从单差浮点模糊度到固定解、验证与保持

### 本周核心问题

RTKLIB 如何从滤波器中的单差模糊度构造双差整数问题，固定后又如何回代位置并管理连续固定？

### 理论与手推（2 h）

1. 推导单差到双差转换矩阵 `D`：`y=D x_c`，`Q_b=D Q_c D^T`，`Q_ab=Q_ac D^T`。
2. 推导条件更新：

   \[
   \hat x_{a|N}=\hat x_a-Q_{ab}Q_b^{-1}(\hat b-\check b)
   \]

   \[
   Q_{a|N}=Q_a-Q_{ab}Q_b^{-1}Q_{ab}^T
   \]

3. 区分 float validation、integer validation、fixed post-fit validation 和 fix-and-hold。
4. 讨论错误固定的危害及 ratio、卫星数、高度角、残差、连续历元等证据的互补关系。

### 源码精读（3 h）

1. `ddidx()`：如何选择参考星并生成单差索引对。
2. `resamb_LAMBDA()`：`y/DP/Qb/Qab/b/s/db/xa/Pa` 的维度与公式映射。
3. `restamb()`、`holdamb()`、`valpos()`。
4. `relpos()` 中 float post-fit、LAMBDA、fixed post-fit、`nfix/minfix/modear` 和最终 `sol.stat`。

### 实验（3 h）

1. 在某个成功固定历元导出 `ix/y/Qb/Qab/b/s/ratio/xa/Pa`。
2. 外部复算 `D`、`Qb`、固定位置更新和固定协方差，核对代码。
3. 扫描 ratio 阈值，统计 float/fix 历元数、首次固定时间和错误固定迹象。
4. 对比 continuous 与 fix-and-hold；观察 `nfix` 和模糊度约束对后续历元的作用。

### 阶段 C 验收（2 h）

- 从 `rtk_t.x/P` 开始，完整推到 `rtk_t.xa/Pa`，每个矩阵都能报出维度。

- 给出至少三种“ratio 通过但仍可能错固定”的原因，并指出可增加的保护条件。

## 6. 防止“读了很多但没有掌握”的规则

1. **每周最多精读 6～8 个核心函数。** 其余只看接口，避免横向扩散到 GUI、网络和所有星座细节。

6. **不以成功固定作为唯一正确性证据。** 同时看 post-fit 残差、标准化创新、协方差、卫星数和时间连续性。

## 8. 未来进入 GNSS/LiDAR 原始观测紧耦合前的接口清单

本计划不实现融合，但完成后应能写出以下边界定义：

- 时间：GNSS 测量时刻、LiDAR/IMU 时刻、时延和同步不确定度。
- 坐标：ECEF、局部 ENU、LiDAR/IMU body frame、天线杆臂。
- 状态：平台位置/速度/姿态、钟差/钟漂、对流层、电离层（按模型）、相位模糊度。
- 原始输入：`obsd_t` 观测、`nav_t` 星历/钟差及其质量信息。
- GNSS 测量输出：零差或双差残差、雅可比、完整协方差、卫星/信号标识、质量标志。
- 生命周期事件：新卫星、失锁、周跳、观测拒绝、参考星切换、float/fix 状态变化。

只有当第 11 周的导出结果能被独立复算，才适合开始把这些量接入 EKF 或因子图；否则融合系统只会把 GNSS 建模错误隐藏在更大的状态空间里。
